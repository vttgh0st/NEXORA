1. Conhecendo o terminal

O terminal permite controlar o Linux através de comandos de texto.

$ pwd

O comando pwd mostra em qual diretório você está.

2. Navegação

Use ls para listar arquivos:

$ ls

Use cd para entrar em uma pasta:

$ cd Documentos

Para voltar:

$ cd ..

3. Criando arquivos e pastas

Para criar uma pasta:

$ mkdir projeto

Para criar um arquivo:

$ touch arquivo.txt

4. Copiando e movendo arquivos

O comando cp copia arquivos:

$ cp arquivo.txt backup.txt

O comando mv move ou renomeia:

$ mv backup.txt backup-final.txt

5. Ajuda no Linux

Você não precisa decorar todos os comandos.

$ ls --help

Também pode consultar o manual:

$ man ls
