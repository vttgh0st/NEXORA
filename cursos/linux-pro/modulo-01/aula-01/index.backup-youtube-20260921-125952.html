🐧 1. O que é Linux?

Linux é o nome utilizado para o núcleo de um sistema operacional baseado no kernel Linux. Ele é utilizado em diferentes tipos de sistemas, desde computadores pessoais até servidores, dispositivos embarcados e outros equipamentos.

Diferentemente de um programa comum, o kernel trabalha em uma camada fundamental do sistema, permitindo que softwares utilizem recursos do hardware.

Resumo: o kernel é uma das partes fundamentais de um sistema operacional e faz a comunicação entre software e hardware.

⚙️ 2. O que é o Kernel?

O kernel é responsável por tarefas fundamentais como gerenciamento de memória, processos, dispositivos e comunicação com o hardware.

Quando um programa precisa acessar recursos do computador, o sistema operacional fornece mecanismos para que essa comunicação aconteça de maneira controlada.

🧩 3. O que são distribuições Linux?

Uma distribuição Linux reúne o kernel com outros componentes necessários para formar um sistema utilizável.

Existem diversas distribuições com objetivos diferentes. Algumas são voltadas para computadores pessoais, outras para servidores, segurança, desenvolvimento ou equipamentos específicos.

Exemplos conhecidos

  • Linux Mint
  • Ubuntu
  • Debian
  • Fedora
  • Arch Linux
  • openSUSE
Importante: Linux e distribuição Linux não são exatamente a mesma coisa. Linux normalmente se refere ao kernel, enquanto uma distribuição combina o kernel com vários outros componentes.

💻 4. O Terminal

O terminal permite interagir com o sistema através de comandos de texto. Ele é uma ferramenta extremamente importante para administração, desenvolvimento e automação.

Um dos primeiros comandos que você pode conhecer é: 

pwd

Esse comando mostra o diretório atual.

Outro comando muito utilizado é: 

ls

Ele lista arquivos e diretórios no local atual.

Exemplo 

pwd
ls

🔐 5. Por que aprender Linux?

Conhecer Linux pode ajudar em áreas como desenvolvimento, administração de sistemas, servidores, automação, programação e computação em geral.

  • Aprender a utilizar o terminal.
  • Administrar arquivos e processos.
  • Automatizar tarefas.
  • Conhecer melhor o funcionamento do computador.
  • Trabalhar com servidores e ambientes Linux.
